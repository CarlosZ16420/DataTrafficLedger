# 仪表盘对照与本轮改进

研究日期：2026-10-15。参考来自各项目官方仓库、公开界面与文档；学习信息组织和交互方式，未复制其源码或图片。

| 参考 | 值得学习的地方 | 本项目的改动 |
| --- | --- | --- |
| [Sniffnet](https://github.com/GyulyVGC/sniffnet) | 总览与连接明细相互配合、主机和应用排行、清楚的网络流量层次 | 增加来源占比和热门网站，保留应用 → 网站 → 原始域名与节点的展开路径 |
| [Netdata](https://github.com/netdata/netdata) | 以趋势图支持排查，明确图表单位和时间范围 | 放大上下行趋势，增加悬停读数、方向键浏览数据点、单时段峰值，缺失记录不连线 |
| [MetaCubeXD](https://github.com/MetaCubeX/metacubexd) | Mihomo 场景下的筛选、主题选择和响应式布局 | 增加深浅主题及跟随系统、筛选摘要与清除、明细排序，调整窄屏布局 |
| [Hamster Archiver](https://github.com/CarlosZ16420/hamster-archiver) | 下载优先的 README、功能场景、可重建的真实界面展示图 | 重写 README，使用同一圆角透明阴影工具生成演示数据截图 |

此前主要差距：趋势图偏小；缺少来源占比与主要网站排行；筛选后不易确认当前条件；缺少排序和深色模式；设置入口不够明确；固定端口与安装脚本增加了初次使用成本。

这轮一并补齐了网页／托盘设置入口、开机自启动状态与路径修复提示、自动空闲端口及占用回退、可携带的偏好设置、可校验的便携发行包。

## 仍然存在的差距

- 当前主要是历史用量账本，未提供秒级带宽仪表、带宽阈值告警和异常检测。
- 未提供历史时段同比环比、可定制布局或多机器集中监控。
- Windows 补充采集以进程和 IP 为主，不能像抓包分析器一样完整解析协议；不保存或解密数据包。
- 图表不为未知时段造数，累计用量也不等同于运营商账单。短连接与停机缺口仍受采样方式限制。
- 当前只有 Windows x64 版本；LINUX DO 是社区友情链接，不表示支持 Linux 系统。

这些功能会改变产品范围和复杂度，未在本轮界面优化中标为已支持。
