# 计量范围、精度与本地数据

## 采集方式

应用读取 Mihomo 活动连接累计计数，每秒采样、每五秒事务写入 Windows 自带 SQLite；明细缓存超过 50,000 条时提前尝试写入。
原始域名、实际节点和规则随记录保存，后续切换节点不会重写历史。
首次启动、检测到内核更换、身份无法确认或计数重置时重新建立基线，不把此前累计量算到当前时段。
临时读取失败保留上一次成功快照；恢复后，只有管道、PID 和进程创建时间均相同且累计计数未回退，才继续计算增量。
每次提交同时保存恢复检查点，包括内核身份、全局累计值、活动连接标识及其累计值。账本重启后按相同条件恢复；检查点与流量原子提交，写入失败时一起回滚。
这类恢复增量记在恢复分钟，并写入状态事件；无法还原中断期间每个原始分钟，也不能找回已经关闭连接的节点和网站归属。
显式配置 `pipe` 时只连接指定管道，失败后不会自动切换到另一内核；未配置时继续自动发现。

连接在两次采样之间结束、关闭前的最后一段、权限不足和停机期间的流量可能无法归属。
全内核累计增量独立保存；差额显示为未归属参考，不分摊给节点，不承诺与每条明细逐字节相等。
页面的“已归属流量”、节点和网站汇总只包含成功保存的明细，不包含这部分未归属差额。
“Clash 流量核对”独立显示所选时段的内核总量、实际保存的 Mihomo 明细及差额，包含代理与直连，只跟随时间范围，不跟随其他筛选。
明细量从实际记录重新汇总，因此旧版缓存丢弃后残留的归属计数不会掩盖差额；若明细暂时大于内核参考，则提示计数重置或采样边界影响，不据此宣称记录完整。
图表是每个时间桶内的累计字节量，不是瞬时网速。缺失记录处不绘制连线。

日期筛选默认包含开始、结束日期的全天记录。取消“包含完整日期”后可指定时分，采用北京时间，
开始分钟和结束分钟均完整包含。例如 15:45—16:00 对应 15:45:00（含）至 16:01:00（不含）的分钟记录。
图表第一次点击选择起点，第二次点击完成选区，第三次点击重新选择起点；反向点击自动交换边界。
有数据的位置按悬停显示的汇总点选取，空白处按时间轴定位到分钟；可在日历面板调整精确时分。
图表保留原日期范围作为上下文，选区用于摘要、明细、来源占比和 CSV；单时段峰值仍对应图表完整范围。
“恢复整天”或“清除筛选”可还原该日期范围。按分钟归档的数据不能拆分成秒级用量。

目前数据库中的 `first`／`last` 是匹配记录最早／最晚的分钟桶，只能代表“有流量记录的分钟”。
Mihomo 连接建立时间随最新恢复检查点保存，但这不是完整连接历史；没有流量的活动连接也不会留下分钟用量。
因此无法据此准确展示节点的“最近连接时间”。该项需要后续确认新增记录，再提供相关界面。

Windows 补充采集只消费原生 ETW 网络事件，不拦截、不重定向、不限速、不保存数据包、不解密 HTTPS。
排除回环与已识别代理核心。TUN 开启或主进程状态不明时暂停补充计量，以避免重复计数；事件丢失会标记。
该来源主要保留进程和 IP，不能保证识别域名；短进程可能只显示 PID。
未经过 Clash 不代表未经过其他 VPN 或代理，Windows 与 Mihomo 的字节口径也不同。

日本筛选按“日本”、🇯🇵、Japan、[JP] 节点名称归类，不通过目标 IP 猜节点位置。
YouTube 等网站分组只是域名归类，展开可查看原始域名。应用不会读取浏览器标签内容。

## 持久化与保留

正常退出会提交待写入记录。意外断电可能丢失最后五秒左右的未提交数据；异常退出后显示未监控区间。
若仅账本异常退出且同一 Mihomo 内核仍在运行，可从已提交检查点继续恢复增量；若机器断电导致内核也重启，旧内核未保存的末段无法恢复。
退出会取消待完成的管道读取，再等待最终提交后关闭数据库。
明细默认保留 90 天，按小时清理过期数据；只读查询不会删除记录。
磁盘空间不足时页面显示写入异常，不能保证无限历史。
只有事务写入失败后，明细缓存才限制为最近 50,000 条；被丢弃明细的字节从归属计数扣除，仍保留在待写入的内核总量中。
内核总量在内存中按分钟合并；磁盘恢复后重试保存并报告丢弃条数。状态事件写入失败不会清空采样基线或终止主采集器。
Windows 补充采集的健康信息与事件写入失败也不会终止采集；写入失败超过缓存容量时保留最近 50,000 条，并在恢复后报告丢弃条数。这部分没有 Mihomo 式累计参考，丢失的 Windows 明细无法补回。
摘要、应用／网站／节点的各层汇总、占比和热门网站排名始终包含全部匹配记录，不再截取前 5,000 组。
明细每页 30 项，展开时才读取下一层，每层均可翻页；翻页只更换可见行，不影响任何汇总值。
一轮查询使用一致的统计快照，新采集记录在刷新后纳入；过期快照会提示刷新。统计读取独立于采集写入，不持有采集锁。
大数据集使用 SQLite 临时文件保存中间结果，最多保留 3 份快照，每份最多缓存 48 个分支、25 万条汇总行（单个超大分支可独占缓存）；不同排序复用分支汇总。闲置 30 分钟后失效，在下次查询或退出时清理。
超过 180 毫秒的加载显示不定进度条；切换筛选会取消旧请求和旧查询。页面最多同时请求 2 页、展开 8 个分支，继续展开时收起较早的分支以控制页面负担。
应用行的路径标签独立汇总全部匹配记录，支持同一应用同时显示代理和直连，并随当前时间、来源等筛选变化。
网站、应用及节点视图的顶层和每级分支同样汇总路径类型；非末级分支列出所有实际代理节点。
节点摘要仅列出 Mihomo 的代理出口，不把 DIRECT 或 Windows 补充采集误标为代理节点。

Windows 补充采集首次授权创建专用高权限计划任务，之后由普通权限托盘调用该任务，登录后不需要重复 UAC 授权。
自动恢复取决于应用是否开启登录自启动；搬迁程序／数据目录、更换用户或任务被删除、禁用时需重新启用授权。
CSV 最多导出 20 万条，超过时需缩小日期范围。

## 与机场账单核对

本地始终记录 Mihomo 提供的原始上下行字节。1.7.0 起默认开启节点倍率估算；关闭“基础设置 → 自动计算节点倍率”可恢复原始展示。两种口径都不包含其他设备或共享账号使用者的流量。
摘要、趋势、各层明细及排序使用同一口径，CSV 同时提供原始字节、展示字节与倍率未知的原始字节。核对区的内核总量、已保存 Clash 明细与差额始终使用原始字节。
新采样在进入缓存前冻结倍率，`rate_usage` 保存每分钟、维度、倍率、来源与是否已确认的原始字节，`billing` 在同一事务累计估算调整与已确认字节。小数倍率不逐次取整，估算聚合采用浮点值，原始字节继续采用整数。
同一分钟内切换倍率也分别保留快照；修改倍率不追溯旧账。未知倍率和没有快照的旧版记录按 1 倍估算，页面单独提示它们的原始字节量。缺少历史依据时不提供自动重算。
应先选定同一节点及同一时间区间，再按机场确认的口径核对：若上下行使用相同倍率，计费参考为 `(上传 + 下载) × 倍率`。
多个节点倍率不同时应逐节点计算后相加；无法归属的内核差额不能随意按某个节点的倍率计费。
机场的节点用量卡片可能展示原始量，也可能展示倍率后的扣费量，需要确认后再比较，避免重复乘倍率。
本页面的 KB／MB／GB 按 1024 换算（对应 KiB／MiB／GiB），其他站点若按 1000 换算，同名 GB 也不相等。
“最近 72 小时”与“近 3 个自然日”的边界不同；本地以分钟保存、服务端更新延迟以及协议计量位置也会影响对账。
首次启动之前、没有可用检查点或内核重启／重置前没有保存的累计量，无法凭现有历史可靠补回。中断日志只说明监控不连续，不证明期间发生了流量。
Windows 补充采集不能补全 Mihomo 已关闭连接的节点和网站归属，也不能消除机场计费口径的差异。

旧版从初始实现起便存在“前 5,000 组”查询截断，仅影响明细响应及由其生成的分组值，不限制数据库保存条数；旧版顶部摘要独立汇总全部匹配事实。
一组是应用、路径、域名、IP、节点等维度的组合，并非一个分钟记录。1.6.0 起采用完整汇总与分页，1.6.1 同样没有这项截断。

## 数据目录

便携版默认将数据写入 EXE 相邻的 `data/`，由 `portable.json` 指定相对位置。
从源码直接构建的 EXE 没有该文件时，沿用当前用户的 `%LOCALAPPDATA%/LocalTrafficLedger`，以兼容英文改名前的历史账本。
`--data <目录>` 可覆盖数据位置。原安装脚本的 `app/` 与相邻 `data/` 布局仍受支持。

| 文件 | 用途 |
| --- | --- |
| `traffic.db`、可能存在的 `-wal`／`-shm` | SQLite 历史账本 |
| `settings.json` | 端口、主题、自动刷新、保留天数及补充采集设置 |
| `nodes.json` | 完整节点目录、检测倍率、导入值及手动锁定，独立于流量数据库 |
| `runtime.json` | 本次启动的端口和访问凭据，不应分享 |
| `capture-state.json` | 主进程状态，供补充采集避免重复计量 |
| `error.log` | 启动失败详情 |
| `icons/` | 可删除的本机应用图标缓存 |

备份前从托盘退出，再复制整个 `data/`。单独复制正在写入的 `.db` 可能遗漏 WAL 内容。
记录含域名、程序路径及节点名称；分享 CSV 或截图前应检查内容。

## 本地访问与资源

仅监听 IPv4 回环 `127.0.0.1`，默认由 Windows 在绑定时分配空闲端口，无探测后再绑定的竞争窗口。
指定端口被占用或受系统限制时回退到动态端口；设置中显示实际地址和回退状态。
旧默认端口 8793／18793 自动迁移；本版明确保存的固定端口仍被保留。
端口设置在下次重启生效，不中断当前页面。通过托盘或双击程序打开，无需手动输入端口。

随机入口建立 HttpOnly、SameSite=Strict 会话。API 校验会话和 Host；写入操作还验证来源和防伪令牌。
脚本、样式及应用图标均由本机提供，无 CDN、遥测和外部字体。

图标仅在接近可见区域时异步加载，最多同时提取两个；没有页面请求时不初始化缓存。
内存最多 128 项／2 MB，磁盘最多 256 PNG／8 MB；按程序路径、更新时间和大小区分，失败时显示字母。
仅支持本地固定磁盘可执行文件，不访问网络路径或外部图标服务。
